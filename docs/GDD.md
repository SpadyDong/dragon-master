| 项目 | 内容 |

| 游戏名 | 驯龙高手（Dragon Tamer Chronicles） |
| 类型 | 2.5D 俯视角 · 模拟经营 + 养成 + 回合制 RPG · 生存探索 |
| 核心体验 | 经营家园、种田养殖、驯龙育龙、自由建造、社交好感、回合制战斗、荒野探索 |
| 参考方向 | 种田（星露谷物语）+ 生存建造（饥荒）+ 回合制人宠对战 + 驯龙养成（原创） |
| 目标用户 | 休闲经营爱好者 · JRPG 玩家 · 养宠收集党 |

### 1.1 核心玩法循环

```
经营家园（种田/养牛羊/驯龙/建造/赚钱）
    ↓ 资源 & 装备准备
探索荒野（采集/钓鱼/挖掘/遇敌）
    ↓ 回合制战斗 & BOSS
成长（加点/武器/龙装备/灵石镶嵌/技能）
    ↓ NPC 社交 & 节日 & 剧情推进
回馈经营（新建筑解锁/新作物种子/稀有龙蛋/NPC 结婚）
```

## 2. 世界观与剧情

### 2.1 原创世界观 — 苍莽大陆

> 遥远的史前苍莽大陆，人类与龙族、荒兽以及肉眼不可见的灵体共存。灵石是万物能量的核心，镶嵌于武器和龙饰之中可催动元素之力。古老传说：四颗散落的灵石圣物，能唤醒沉睡的龙灵王，逆转大陆被黑暗吞噬的宿命。

### 2.2 三幕式主线剧情

**第一幕 · 村落启程（春）**
- 主角（开局可选男/女）来到边陲小镇「龙脊镇」投奔亲人
- 继承一块荒废的土地，开始经营家园
- 结识镇上 40 名居民，在武器商店、龙之商店、铁匠、渔店、面包房等商铺打工与交易
- 驯服第一只幼龙，遭遇荒兽袭击村落事件

**第二幕 · 集结探索（夏→秋）**
- 得知灵石圣物传说，开始向和平区外的荒野、火山、雪山、天空遗迹探索
- 结识 10 位特殊地点 NPC（守墓人、火山铁匠、雪山隐士、天空遗族等），解锁新的元素装备锻造
- 集齐 4 颗灵石圣物：风息石、炎心石、潮涌石、霜魄石
- 每颗圣物对应一场 BOSS 战（元素化的远古守护龙）

**第三幕 · 宿命对决（冬）**
- 黑暗势力带着腐化龙族降临，威胁龙脊镇与整片大陆
- 集结伙伴、家族、最强龙族、全部可结婚角色支援
- 登上天空浮岛，最终回合制决战黑暗龙灵王
- 多结局：单人结局 / 伴侣结局 / 家族繁荣结局 / 归隐结局

### 3.1 性别选择（硬性规则）
- **玩家必须在开局选择性别：男 / 女**（影响可结婚对象，仅允许异性结婚）

| 属性 | 作用 |
|---|---|
| 力量（STR） | 攻击加成，双手剑伤害提升 |

## 5. 和平区域系统（龙脊镇 & 主角家园）

### 5.1 种植系统

**地块状态机**：空地 → 锄地 → 播种 → 浇水（每日） → 发芽 → 生长阶段 ×N → 成熟（可收获）

**要素**：
- 春/夏/秋/冬专属作物（每种 10+）
- 品质分级：普通 → 银星 → 金星 → 紫星（价格×0.5/×1/×2/×3.5）
- 肥料加速生长、提升品质
- 温室（剧情解锁后四季可种）
- **果树**：每年产果 2 季，树龄越久产果越多
- **巨化作物**：极低概率，收获量×5
- **洒水器**：铜/铁/金三级，自动浇灌相邻地块
- **蜂箱**：附近花朵自动产蜜，稀有花产稀有蜜

### 5.2 畜牧与养龙系统

#### 5.2.1 普通畜牧
| 种类 | 产出 | 建筑 |
|---|---|---|
| 鸡 | 蛋、羽毛、鸡块 | 鸡舍 |
| 鸭 | 鸭蛋、鸭毛、鸭肉 | 鸡舍 |
| 猪 | 松露（秋冬野外放养老概率）、猪肉 | 猪圈 |
| 牛 | 牛奶、黄油、奶酪、牛肉 | 牛棚 |
| 羊 | 羊毛、羊肉 | 羊圈 |
| 山羊 | 山羊奶、山羊奶酪 | 羊圈 |
| 兔子 | 兔毛、兔肉 | 兔舍 |
- 动物心情度影响产出品质，需要每天抚摸、喂食、放牧

#### 5.2.2 养龙系统（核心特色）
- **成长阶段**：蛋 → 孵化 → 幼龙 → 青年龙 → 成年龙 → 老龙（退役）
- **四维成长**：攻击 / 防御 / 敏捷 / 生命（个体值+努力值）
- **心情度**：影响战斗力与交配意愿
- **骑乘系统**：青年龙及以上可骑乘，提高移动速度，部分地形可跨越
- **捕捉**：野外回合制战斗中削弱血量后用专用道具（肉/网/麻醉）捕捉
- **融合培育**：同属性父母龙有概率诞生更高天赋二代
- **龙蛋硬上限（核心规则）**：**每只龙一生最多产 2 颗蛋**，稀有龙必须珍惜
- **交配季**：主要在春秋，情绪值满才能触发
- **龙食槽**：自动喂食设施，减轻玩家日常负担

### 5.3 NPC 系统（40 普通 + 10 特殊占位）

#### 5.3.1 NPC 基础规则
- **40 名小镇常驻 NPC**：覆盖男女老少，有家庭关系（父母/兄弟姐妹/夫妻/子女）
- **10 名特殊地点 NPC**：先留坑，后续剧情解锁后补充
- 每名 NPC 有**固定住所**（建筑清单里列出），上班时段出现在工作地点，下班在家/闲逛，上下班路径可见
- 对话内容动态：随早/中/晚、季节、天气、好感度、任务状态、主角近期行为而变
- 家庭关系联动：结婚后 NPC 的家人对主角态度变化

## 6. 非和平区域系统

### 6.1 探索与生存（参考饥荒 · 回合制战斗）

**生存四要素**：
| 要素 | 作用 | 耗尽惩罚 |
|---|---|---|
| 体力（Energy） | 种田/挖矿/钓鱼/战斗均消耗 | 晕倒，强制回家，丢失部分携带物 |
| 饥饿（Hunger） | 每小时下降，进食回复 | 持续掉血 |
| 生命（HP） | 被攻击、熬夜、受伤下降 | 0 → 濒死，送回并掉钱 |
| 灵力（MP） | 释放咒术/治疗/元素技能 | 无法使用技能 |

**昼夜影响**：
- 夜晚：视野受限（需火把 / 龙灯），野怪更凶猛但稀有掉落概率提升
- 冬季：严寒额外消耗体力，需要厚衣服 / 龙火取暖
- 雷暴：不可进入高原和树下，有概率被雷击

### 6.3 元素属性系统（参考原神）

#### 6.3.1 五大基础属性 + 预留扩展
| 属性 | 代表色 | 特点 |
|---|---|---|
| 风 | 青绿 | 速度快、扩散、群攻 |
| 火 | 赤红 | 高爆发、燃烧 DOT |
| 水 | 深蓝 | 治疗、冰冻前置、蒸发 |
| 土 | 棕黄 | 防御、结晶护盾、坦克 |
| 冰 | 冰蓝 | 控制冻结、减速 |
| 雷 | 紫色 | 预留扩展（秋·雷羽龙） |
- 人和龙均可能为**单属性或双属性（主+副）**

#### 6.3.2 属性克制循环
```
火 → 克 → 冰（×1.5）→ 克 → 风（×1.5）→ 克 → 土（×1.5）→ 克 → 水（×1.5）→ 克 → 火（×1.5）
```
- 克制方：**伤害 ×1.5**
- 被克方：**伤害 ×0.75**
- 同属性抗性：伤害 ×0.5

#### 6.3.3 元素反应（双属性触发）
| 组合 | 名称 | 效果 |
|---|---|---|
| 火 + 水 | 蒸发 | 伤害 ×1.5 |
| 火 + 冰 | 融解 | 伤害 ×2.0 |
| 水 + 冰 | 冻结 | 目标 1 回合不可行动 |
| 土 + 任意 | 结晶 | 产生护盾，吸收一次大额伤害 |
| 风 + 任意 | 扩散 | 溅射相邻敌人 ×0.6 |
| 雷 + 水（预留） | 感电 | 两回合持续雷电伤害 |
| 雷 + 火（预留） | 超载 | 范围爆炸 |

#### 6.3.4 属性与季节联动
- 夏季：火属性伤害 +20%，水属性 -10%
- 冬季：冰属性 +20%，火属性 -10%
- 春季：风属性 +20%，土属性 -10%
- 秋季：土属性 +20%，风属性 -10%

### 6.4 人物武器与装备系统

#### 6.4.1 三种武器类型（仅限人物，龙用龙装备）

| 武器 | 攻击范围 | 攻速 | 核心优势 | 适合属性 |
|---|---|---|---|---|
| 单手剑 | 近战 1 格 | 快 | 暴击率高、可持盾 | 全属性通用 |
| 双手剑 | 近战 2 格横扫 | 慢 | 高攻击、群伤 | 火 / 土 |
| 弓箭 | 远程 3–5 格 | 中 | 先手、可打飞行 | 风 / 水 / 冰 |
- 武器熟练度：频繁使用可解锁武器专属被动
- 战斗中可切换武器（消耗 1 次行动的 50%）

#### 6.4.2 装备与元素属性绑定（核心规则）
- 所有武器 / 防具 / 饰品 / 龙装备均带有**元素属性标签**
- **人物装备规则**：必须与人物主属性匹配，否则：
  - 匹配：属性伤害加成 **100%**，可发动元素反应
  - 不匹配但同类武器：攻击削减至 **50%**，无法触发元素技能
  - 完全不符：不可装备
- **龙装备规则**：龙鞍 / 龙鳞甲 / 龙饰必须匹配龙的主属性，否则龙心情下降，元素技能被禁用

#### 6.4.3 品质分级（6 档）
白 → 绿 → 蓝 → 紫 → 橙 → 红（传说），每档附加属性加成阶梯上升

#### 6.4.4 获取与强化
| 方式 | 说明 |
|---|---|

| 龙之商店 | 购买/锻造/升级龙鞍、龙鳞甲、龙饰，龙饰附灵附加元素效果 |

| BOSS 掉落 | 紫–橙装，附带唯一词条 |
| NPC 赠送 | 心事件或婚后，赠送定制装备 |

|---|---|

#### 6.5.3 特色战斗机制

- **捕捉**：血量越低成功率越高，属性克制加成，专用捕捉道具
- **元素反应**：6.3 节所有反应在战斗中实时结算

## 10. 技术方案（Unity + C#）

### 10.1 模块划分
```
Assets/Scripts/
├── Core/                — GameManager、存档系统、事件总线
├── TimeSeason/          — 昼夜+季节+天气+节日调度

├── Equipment/           — 单手剑/双手剑/弓箭三系、龙装备、属性绑定、强化镶嵌
├── Combat/              — 回合制状态机、暴击、合击、捕捉、元素反应结算

├── Livestock/           — 鸡猪牛羊兔、心情、产出、松露、加工机
├── Fishing/             — 钓点、鱼种表、QTE、鱼塘、图鉴
├── Terrain/             — 上下坡/悬崖/海边/雪山/湖泊/桥梁/冰面
├── NPC/                 — 50名NPC数据表、行为轨迹、关系网、上班/下班/回家
├── Affection/           — 好感度、礼物偏好、心事件触发
├── Dialogue/            — 双层对话演出（普通+分屏剧情）、选项、回看
├── Marriage/            — 求婚、婚礼、住所切换、生育、配偶日常
├── Festival/            — 节日小游戏、奖励、游行
├── CommunityCenter/     — 收集包、议事厅、龙腾集团路线
├── Mining/              — 四层矿洞、电梯、铱矿、宝箱、BOSS
├── Cooking/             — 食谱、烹饪台、buff
├── Crafting/            — 建造加工机、锻造、撒水器、蜂箱、制粉
├── Skill/               — 5技能+5/10级分支职业
├── Museum/              — 捐赠、图鉴、成就、图书馆
├── MailCalendar/        — 邮件、日历、求助告示板
```

- 格式：JSON（人类可读，便于调试）+ 加密校验

- 保存内容：世界状态（季节/天气/建筑位置/地块生长/龙状态/NPC位置好感/背包/装备/技能）
