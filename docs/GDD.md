```

    ↓ 资源 & 装备准备
探索荒野（采集/钓鱼/挖掘/遇敌）

```

## 2. 世界观与剧情

### 2.1 原创世界观 — 苍莽大陆

> 遥远的史前苍莽大陆，人类与龙族、荒兽以及肉眼不可见的灵体共存。灵石是万物能量的核心，镶嵌于武器和龙饰之中可催动元素之力。古老传说：四颗散落的灵石圣物，能唤醒沉睡的龙灵王，逆转大陆被黑暗吞噬的宿命。

### 2.2 三幕式主线剧情（详细）

**前置剧情 · 觉醒之日**
> 夜幕中，一颗灵流星坠入苍莽大陆东隅无名谷。翌日清晨，一位黑斗篷旅人敲开龙脊镇老村长的大门，递上一封泛黄的信——信纸边角印着主角家族的灵纹标记。信上只有两行字：**"当灵流星坠落第三日，继承者将踏浪而来。请将山脚下荒废了二十年的那块地，交给他。"** 发信人是 20 年前在"虚空裂缝之战"中失踪的驯龙宗师——**主角的祖父**。

**第一幕 · 村落启程（春 · 第 1~28 天）**

| 阶段 | 触发条件 | 剧情事件 |
|---|---|---|
| 1-1 初抵 | 开局自动 | 主角乘小舟沿苍莽河而下，在东港口登岸。马夫老李牵来一匹老马："你爷爷托我照看这块地二十年了。" 主角获得：锈锄头×1、芜菁种子×5、500 文、破损的龙哨（无法使用） |
| 1-2 安家 | Day 1 自动 | 老村长带主角认地——山脚下被藤蔓覆盖的木屋。主角清理杂草、修葺屋顶。夜晚，在屋后枯井下隐约听到微弱的龙鸣。 |
| 1-3 初识 | Day 2-3，种下第一批作物后 | 阿岚主动上门："听说你是宗师的后人，来看看。" 赠送风灵石碎片×1。他提到武器商店就在广场旁，欢迎主角去打工学艺。 |
| 1-4 打工 | Day 3-7，任意商铺对话 | 可选去阿岚（武器店）、磐石（龙商店）、铁梅（铁匠铺）、青野（面包房）、云涛（渔店）处打工。每日 4 小时，赚 50-120 文 + 对应技能熟练度。 |
| 1-5 枯井龙鸣 | Day 5 后，夜晚去屋后枯井 | 触发短剧情：枯井深处封着一颗未孵化的幼龙蛋——祖父 20 年前留下的最后一只龙。蛋壳布满裂纹但未破。老村长说："需要灵石温度才能孵化。" 主角用阿岚送的风灵石碎片贴上去 — 蛋壳裂开，孵出落叶龙幼崽「翠翠」。 |
| 1-6 驯龙初战 | Day 7-10，带翠翠到广场 | 小石（阿岚的弟弟）惊喜地跑过来摸龙。突然，野外方向传来吼声——一只失控的荒兽·石甲犀冲入镇口。阿岚持剑挡在第一线，主角带翠翠应战。**M1 教程 BOSS 战**：石甲犀（HP 80，弱风）。战后阿岚正式邀请主角加入驯龙师行列。 |
| 1-7 春祭 | Day 14 自动 | 春耕祭：全镇在广场摆宴。卯师傅主厨"春野全席"；叶铃登台弹唱；澄溪用花装饰全场；暮晴讲述春灵石传说。此日所有 NPC 好感 +10。 |
| 1-8 幕末 · 老村长的托付 | Day 24-28，好感≥100 找老村长 | 老村长将祖父留下的"驯龙笔记"交给主角。笔记中记载了四颗灵石圣物的方位和两位守门人的名字。笔记末页写道："当你集齐四圣物之日，来天空浮岛找我。——祖父。" 第一幕结束，解锁野外区域（火山、雪山、森林）。|

**第二幕 · 集结探索（夏→秋 · 第 29~84 天）**

| 阶段 | 触发条件 | 剧情事件 |
|---|---|---|
| 2-1 风息石（火山） | 夏，进入火山区域 | 在火山山麓遇到 **S1·火山守林人·赤焰**（暴躁正义的中年驯龙师，曾是祖父的弟子）。他看守风息石千年，要求主角通过试炼：在岩浆洞窟中击败炎心龙（BOSS，HP 300，弱水）。胜利后赤焰将风息石交给主角，并答应在最终战时加入支援。 |
| 2-2 炎心石（沙漠） | 夏末，前往沙漠绿洲 | 沙漠商队首领 **S4·哈桑**（豪爽的商人）告知炎心石被沙虫王吞入腹中。主角在流沙地带追踪沙虫王（BOSS，HP 400，弱冰），击败后从腹中取出炎心石。哈桑赠送骆驼坐骑和沙漠特产「星沙香料」（卯师傅超爱）。 |
| 2-3 潮涌石（海底遗迹） | 秋，与云涛好感≥500 | 云涛说他祖父曾在东海深处见过发光的遗迹。二人乘船出海，在海底遗迹入口遇到 **S9·海盗船长·罗刹女**（飒爽独眼女船长，因潮涌石的诅咒被困于此）。她提出交易：帮她破除诅咒，潮涌石归主角。在遗迹底层与「深渊守护者」（BOSS，HP 500，弱雷）战斗。胜利后潮涌石到手。罗刹女成为海上快速旅行 NPC。|
| 2-4 霜魄石（雪山冰窟） | 秋末，进入雪山深处 | 在雪峰之巅遇见 **S2·雪山隐士·白霜**（沉默寡言的白发女子，操纵冰元素）。她守护霜魄石已经 50 年，因孤独而犹豫是否交出。主角需要连续 7 天每天上山为她送一杯热茶（卯师傅的姜茶最好），第 7 天她将霜魄石赠予主角，并流着泪说："这是我 50 年来第一次有人跟我说话。谢谢。" 白霜在第三幕作为强力友方 NPC 参战。|

**第三幕 · 宿命对决（冬 · 第 85~112 天）**

| 阶段 | 触发条件 | 剧情事件 |
|---|---|---|
| 3-1 黑暗降临 | 冬 1 日自动 | 天空变得暗红。龙脊镇上空出现巨大旋涡裂隙，黑暗龙灵王的先遣军——腐化龙族——如蝗虫般涌出。全镇 NPC 进入紧急状态：男人们持武器守镇口，女人们护送孩童进入议事大厅避难。老村长翻开祖父笔记，发现最后一页浮现出之前不可见的文字。 |
| 3-2 最后的灵纹 | 冬 1 日夜里 | 笔记中写道：龙灵王本是守护大陆的原初之龙，因被虚空侵蚀而腐化。钥匙不在圣物——在圣物的持有者身上。四颗灵石圣物需要四位持有者分别注入心力，才能开启前往天空浮岛的通道。主角需要选出三位同伴同行。所有好感度 ≥500 的可结婚对象和非可结婚 NPC 都可以被选为"同行者"。 |
| 3-3 天空浮岛 | 选定同伴后 | 四位持有者将圣物嵌入古钟，大爷爷敲钟 12 响，通往天空浮岛的云梯现形。在浮岛上穿越 4 个领域（风暴/烈焰/深海/冰封），每领域一场精英战。最终抵达龙灵王王座。 |
| 3-4 最终战 | 进入王座 | 黑暗龙灵王（双阶段 BOSS）：第一阶段 HP 2000，七元素轮换；第二阶段 HP 3500，持续召唤腐化龙。同伴们在战斗中各有专属剧情动作（如阿岚放风盾、白霜用冰封给主角回血）。胜利后，主角可选择净化龙灵王或消灭它。 |
| 3-5 结局分歧 | 战后 | 1️⃣ **单人结局**：龙灵王被净化，主角独自守护龙脊镇，天空浮岛降为新的和平区域。2️⃣ **伴侣结局**：与结婚对象一起生活，CG 动画展示婚后日常。3️⃣ **家族繁荣结局**：孩子出生，主角成为新一代驯龙宗师，龙脊镇扩建为龙脊城。4️⃣ **归隐结局**：带上最爱的龙，和伴侣一起离开龙脊镇，去探索苍莽大陆的未知之地。|

### 2.4 新手引导 · 七日引导流程

> 新手引导通过自然剧情推进，而非弹窗教学，让玩家在第一周（游戏 7 天）内逐步掌握核心操作。

| 天数 | 触发 | 教程内容 | 完成奖励 |
|---|---|---|---|
| **Day 1** | 自动 | ① 老村长带路 → WASD 8方向移动；② 到荒地 → 按 F 用锄头锄地、播种、浇水；③ 回木屋 → 接触"床"交互 → 睡觉保存 | 芜菁种子×5、锈锄头×1、洒水壶×1 |
| **Day 2** | 自动 | ① 起床 → 提示"按 M 打开地图查看全镇位置"；② 出门 → 田里芜菁发芽了（展示作物生长）；③ 走向广场 → NPC 对话系统引导"靠近 NPC → 按 F 交谈" | 金币 +100 |
| **Day 3** | 去武器店 | 阿岚引导打工系统：按 F 与柜台交互 → "打工 4 小时"选项 → 获得报酬。同时介绍"熟练度"概念：打工增加对应熟练度 | 风灵石碎片×1、金币 +80 |
| **Day 4** | 去饭馆 | 卯师傅介绍菜市场："每天价格牌子上的价钱不一样，种多了同一种菜，价钱会跌。" 点卯师傅的"今日菜单"试吃一道菜（免费），了解食物恢复体力/饥饿。 | 体力全满 |
| **Day 5** | 自动—田里 | NPC 阿岚路过，教工具升级："把锈锄头带去铁匠铺找铁梅，花铜锭可以升级成铜锄头。" 演示背包（按 E） | 铜锭×5 |
| **Day 6** | 去铁匠铺 | 铁梅展示装备系统：① 按 Q 打开装备栏；② 武器影响战斗伤害；③ 防具减少所受伤害。并赠送初级防具一件。 | 布衣×1 |
| **Day 7** | 枯井剧情 | 触发幼龙孵化剧情（见第一幕 1-5）。孵化后阿岚引导简单的龙养成教学：喂食、抚摸、命名。 | 落叶龙幼崽×1、龙食×10 |

> 七天后，玩家已掌握：移动/种田/浇水/睡觉/地图/NPC对话/打工/菜市场/烹饪/体力系统/装备/背包/养龙。此后自由探索。所有引导信息可在"帮助"菜单（H 键）中回看。

## 3. 开局角色创建

### 3.1 性别选择（硬性规则）
- **玩家必须在开局选择性别：男 / 女**（影响可结婚对象，仅允许异性结婚）
- 性别可附带外观预设：肤色、发色、发型、瞳孔颜色、初始服装

### 3.2 初始属性分配（5 点可分配）
| 属性 | 作用 |
|---|---|
| 力量（STR） | 攻击加成，双手剑伤害提升 |
| 敏捷（AGI） | 先手速度、暴击率、弓箭伤害、闪避 |
| 体质（VIT） | 生命值上限、饥饿耐久、挖矿耐力 |
| 智慧（INT） | 灵力上限、咒术/治疗效果、元素伤害加成 |

## 4. 季节与时间系统

### 4.1 四季循环

| 季节 | 天数 | 特征 | 专属龙种 |
|---|---|---|---|
| 春 | 28 | 万物复苏，降雨多，作物生长快 | 落叶龙（风） |
| 夏 | 28 | 炎热干旱，火山活动，海边繁盛 | 焰心龙（火） / 潮鸣龙（水） |
| 秋 | 28 | 收获季节，落叶，神秘森林出现 | 雷羽龙（雷·预留扩展） |
| 冬 | 28 | 大雪封山，湖面结冰可通行 | 霜翼龙（冰） |

### 4.2 时段划分（1 天 ≈ 现实 14 分钟）
| 时段 | 游戏时间 | NPC 行为 |
|---|---|---|
| 清晨 | 06:00–08:00 | 起床、在家 / 上班路上 |
| 上午 | 08:00–12:00 | 在岗上班（铁匠/渔店/面包房等开店） |
| 中午 | 12:00–14:00 | 午餐 / 短暂休息 |
| 下午 | 14:00–18:00 | 继续上班或下班回家路上 |
| 傍晚 | 18:00–20:00 | 闲逛 / 回家 |
| 夜晚 | 20:00–24:00 | 在家，部分不可拜访 |
| 深夜 | 24:00–06:00 | 全体休息，强行走入熬夜扣体力 |

### 4.3 天气系统（独立章节 · 6 种核心天气）

| 小雨 🌧️ | 雨滴 | 春夏秋 | 15% |

#### 4.3.2 对种植系统的影响
| 天气 | 作物生长速度 | 需人工浇水 | 特殊影响 |
|---|---|---|---|
| 晴 | 基准 1.0× | 需要（每日） | — |
| 小雨 | +15%（水分充足） | 不需 | — |
| 雷暴 | +20% | 不需 | 低洼地块 5% 概率被冲毁（需重新锄地） |
| 小雪 | -20% | 不需 | 露天作物 10% 冻伤（品质降 1 档） |
| 大雪 | -50% | 不需 | 露天作物 30% 冻伤；果树果实 20% 掉落 |
| 大风 | -10% | 需要 | 高树、藤蔓类 15% 概率断枝减产；洒水器效率 ×0.6 |
| 雾天 | ±0 | 需要 | 作物病害概率 +10%（次日检查） |

| 天气 | 稀有鱼出现 | 咬钩速度 | QTE难度 | 限定 |
|---|---|---|---|---|
| 晴 | 基准 | 快 | 标准 | 阳属性鱼 +10% |
| 小雨 | +20% | 快 | -20% | 溪流鱼、河鱼加成 |

#### 5.3.8 支线任务系统

> 设计原则：每个 NPC 至少 1 个独立支线任务。奖励锁定在"不影响主线平衡"的范围内——菜谱、家具、道具、装备、增益等。所有支线任务均可跳过，不阻塞主线进度。

**任务状态机**

```
Locked → Available（满足解锁条件）→ Active（玩家接取）→ Completed（达成目标）
```

**解锁条件**：好感度阈值 / 游戏天数 / 季节 / 前置任务完成

**奖励类型**

| 类型 | 示例 | 说明 |
|---|---|---|
| 道具 | 古钟余音、战争故事集 | 一次性消耗品或永久收藏品 |
| 菜谱 | 火焰面包配方、云腾八珍锅、幸福蛋糕 | 解锁新烹饪配方 |
| 家具 | 木雕置物架、花园喷泉、音乐盒、猫猫小屋 | 家园装饰 |
| 装备 | 矿工头盔、金色鱼竿、灵纹护符、熔岩之心 | 有实际属性的装备 |
| 增益 | 避毒坠、折扣卡、猎人披风、洁净香囊 | 永久被动效果 |
| 解锁 | 酒吧VIP座位（每周五免费1杯） | 功能性解锁 |

### 5.4 对话演出系统（双层）

- 屏幕底部对话框（石板+兽皮材质）

- 头像表情随好感度/上下文动态切换：开心 / 微笑 / 平静 / 疑惑 / 害羞 / 生气 / 惊讶 / 哭泣，共 8 档

- **分屏布局**：
  - 2 人对话 → 左右二分立绘

| **冻结** | 水 ↔ 冰 | 基础伤害 ×0.5，目标 **1 回合不可行动**；被火/岩打击时碎冰追加伤害 |
| **结晶** | 岩 + 火/水/冰/雷 | 不直接伤害，生成元素护盾（减伤 30%，吸收该元素 1 次大额攻击） |
| **扩散** | 风 + 火/水/冰/雷 | 基础伤害 ×0.8，元素向全场 **3 格内溅射**，引爆多次连锁反应 |

核心函数：
- `getElementReaction(atkElement, defElement)` → 返回反应名与倍率
- `calcReactionDamage(baseDmg, atkElement, defElement, level)` → 返回伤害值 + 反应 + 可能生成的护盾/DOT

#### 6.3.3 属性克制 & 抗性
- 同属性抗性：对同元素伤害 **×0.5**
- 双属性个体：按两种抗性取较高者
- 季节元素加成：
  - 春：草 +20% / 风 +15%
  - 夏：火 +25% / 水 +10%
  - 秋：雷 +20% / 岩 +10%
  - 冬：冰 +25% / 火 -10%

### 6.4 人物武器与装备系统

#### 6.4.1 三种武器类型（仅限人物，龙用龙装备）

| 武器 | 攻击范围 | 攻速 | 核心优势 | 适合属性 |
|---|---|---|---|---|
| 单手剑 | 近战 1 格 | 快 | 暴击率高、可持盾 | 全属性通用 |
| 双手剑 | 近战 2 格横扫 | 慢 | 高攻击、群伤 | 火 / 土 |

- 战斗中可切换武器（消耗 1 次行动的 50%）

#### 6.4.2 装备与元素属性绑定（核心规则）
- 所有武器 / 防具 / 饰品 / 龙装备均带有**元素属性标签**
- **人物装备规则**：必须与人物主属性匹配，否则：
  - 匹配：属性伤害加成 **100%**，可发动元素反应
  - 不匹配但同类武器：攻击削减至 **50%**，无法触发元素技能
  - 完全不符：不可装备
- **龙装备规则**：龙鞍 / 龙鳞甲 / 龙饰必须匹配龙的主属性，否则龙心情下降，元素技能被禁用

#### 6.4.3 品质分级（6 档）
白 → 绿 → 蓝 → 紫 → 橙 → 红（传说），每档附加属性加成阶梯上升

- 示例委托：「我家小孩想吃鱼」送 1 条普通鱼 → 奖励 50 文 + 委托 NPC 好感 +10；「矿洞事故」采 10 铜矿 → 奖励 200 文 + 工会声望 +3
- 过期委托次日自动失效重刷

### 7.11 马 + 宠物（猫狗）+ 坐骑龙

#### 7.11.1 马
- 从马厩向马夫老李购买：10,000 文，配 1 个马鞍
- 和平区 / 非和平区通用移动速度 +100%
- 配道具「马笛」：任意地点吹响，马 3 秒内奔跑到主角身边接驾

#### 7.11.2 宠物 · 猫 / 狗（开局必选 1 只，龙之外的暖心陪伴）

| 宠物 | 性格倾向 | 日常行为 | 特殊奖励机制 |
|---|---|---|---|
| 🐶 中华田园犬（大黄/小黑等） | 外向、忠诚 | 每天早晨在门口摇尾巴；跟随玩家；对陌生人 NPC 吠叫提醒 | 连续抚摸 7 天 →「寻宝鼻」：每周 1 次在地图上扒出随机掉落（矿石/种子/秘纸条） |
| 🐱 橘猫 / 狸花 / 三花 / 奶牛猫 | 独立、傲娇 | 在家随机位置睡觉 / 晒太阳 / 爬树 / 抓蝴蝶 / 偷嘴 | 连续投喂小鱼干 7 天 →「报恩」：下雨天 / 雷暴天叼回稀有道具（高值鱼/宝石）；满好感后偶尔睡在枕边：次日幸运 +15% |

**通用宠物机制**：
- 宠物不进入战斗，也不死；仅存在于和平区家园
- 每日抚摸 + 1 次喂食（猫粮/狗粮，菜市场或厨子处可购）；饿 3 天离家出走 → NPC 处需 300 文赎回
- 好感度 Lv 满后：玩家回家时自动触发「宠物迎接动画」，心情系统永久每日 +3 上限
- 后期可花 20,000 文同时饲养猫狗各 1 只，猫追狗打闹动画为家园增添生气

#### 7.11.3 坐骑龙
- 青年龙训练骑乘技能 → 成年后解锁；比马速度快 20%
- 部分地形可直接跨越：悬崖（飞属性龙）、浅滩急流（水属性龙）、火山熔岩（火属性龙冰面不滑）
- 骑乘龙进入战斗：第一回合自动获得「骑乘加成 BUFF」×15% 全属性

### 7.12 温泉 / 澡堂
- 雪山脚下温泉（冬）+ 镇南澡堂（全年），泡澡恢复体力 / 生命 / 灵力全满
- 偶发 NPC 共浴事件（提升好感）

### 7.13 冒险工会
- 赤霄担任副会长
- 接取讨伐任务（指定击杀 N 只某怪物），奖励金币+工会点
- 工会点可兑换回程法杖、高级装备、稀有龙蛋
- 击杀数里程碑（累计击杀 1000 / 10000）解锁额外奖励

### 7.14 秘密纸条 & 怪奇收集
- 矿洞 / 钓鱼 / 觅食概率得到编号秘密纸条（1–50），内容为：NPC 秘密、隐藏道具位置、谜题、笑话
- 集齐解锁怪奇收藏家成就

### 7.15 爷爷的评估（祖辈传承）
- 游戏内第 3 年春 1 日，主角祖辈的灵魂回家评估家园
- 根据家园繁荣度、图鉴完成度、好感度、剧情进度给出 0–4 盏蜡烛
- 4 盏完美奖励：稀有龙蛋 + 永久幸运 buff

### 7.16 星陨果（永久提升）
- 隐藏在地图各处的 7 颗星陨果，每颗永久 +1 项属性上限（体力+30 / 生命+20 / 灵力+10 / 暴击率+1% 等）

### 7.17 Qi 先生挑战（龙灵试炼）
- 通关最终 BOSS 后解锁
- 高难度战斗挑战、限时收集、特殊商店兑换稀有龙装备

### 7.18 垃圾桶搜刮
- 全镇商铺门口各有垃圾桶，每日可翻找（随机获得食物/材料/垃圾）
- 被 NPC 看到会降低好感度

```
Assets/Scripts/
├── Core/                — GameManager、存档系统、事件总线

├── Dragon/              — 龙成长、元素属性、克制反应、产蛋（上限2）、骑乘
├── Equipment/           — 单手剑/双手剑/弓箭三系、龙装备、属性绑定、强化镶嵌
├── Combat/              — 回合制状态机、暴击、合击、捕捉、元素反应结算
├── Building/            — 自由建造、蓝图、升级、NPC固定屋
├── Farming/             — 种植、洒水器、温室、果树、巨化作物、蜂箱
├── Livestock/           — 鸡猪牛羊兔、心情、产出、松露、加工机

├── Festival/            — 节日小游戏、奖励、游行
├── CommunityCenter/     — 收集包、议事厅、龙腾集团路线
├── Mining/              — 四层矿洞、电梯、铱矿、宝箱、BOSS
├── Cooking/             — 食谱、烹饪台、buff
├── Crafting/            — 建造加工机、锻造、洒水器、蜂箱、中式工匠设备（酱缸/豆腐坊/磨坊/腊肉架/糖坊/织机/酿酒桶/榨油机）
├── Proficiency/         — 6大熟练度（种植/畜牧/钓鱼/战斗/采集/社交）+ 每10级专精二选一 + 武器子熟练度
├── Restaurant/          — 卯时饭馆：固定菜单/季节特供/隐藏菜品/来料加工/周日圆桌宴
├── Market/              — 菜市场：每日价格公告板/七类商品波动/供需下跌/经营者折扣/种子树苗销售
├── Museum/              — 捐赠、图鉴、成就、图书馆
├── MailCalendar/        — 邮件、日历UI、NPC生日、求助告示板
├── Transport/           — 矿车、回程法杖、方尖碑、金色时钟、马、宠物（猫/狗）
├── AdventureGuild/      — 任务、讨伐、工会点
├── Secrets/             — 秘密纸条、星陨果、爷爷评估、Qi试炼
├── UI/                  — 4K矢量、Y-sort、自适应
├── Audio/               — BGM+音效、混音器淡入淡出
└── SaveLoad/            — JSON + 多槽位 + 自动存档
```

### 10.2 存档
- 格式：JSON（人类可读，便于调试）+ 加密校验
- 槽位：5 手动 + 1 自动（每 10 分钟）
- 保存内容：世界状态（季节/天气/建筑位置/地块生长/龙状态/NPC位置好感/背包/装备/技能）
